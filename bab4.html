02 · Pemantik

Mengapa VLAN perlu dihubungkan?

Sebuah perusahaan memiliki tiga divisi: VLAN 10 — Administrasi, VLAN 20 — Keuangan, dan VLAN 30 — IT. Setiap divisi memiliki subnet IP berbeda. Pada BAB 3 kamu sudah belajar memisahkan jaringan dengan VLAN.

03 · Review Prasyarat

Review Singkat dari BAB 3

Klik setiap kartu untuk membuka penjelasan singkat. Hanya konsep yang menjadi prasyarat Inter-VLAN Routing yang diulas di sini.

Apa yang terjadi ketika PC VLAN 10 mengirim paket menuju PC di VLAN 20?

PC membandingkan alamat IP tujuan dengan IP dan subnet mask miliknya. Karena 192.168.20.10 berada di luar jaringan lokal 192.168.10.0/24, PC tidak mengirim langsung ke tujuan. Paket dikirim ke default gateway (alamat router pada VLAN 10), lalu router yang menentukan jalur menuju jaringan VLAN 20.
04 · Konsep Inti

Pengertian Inter-VLAN Routing

Inter-VLAN Routing adalah proses meneruskan paket dari satu VLAN ke VLAN lain menggunakan perangkat Layer 3 (router atau Layer 3 Switch). Karena setiap VLAN biasanya memiliki subnet IP sendiri, perpindahan antar-VLAN adalah perpindahan antar-subnet, dan itu adalah tugas routing, bukan switching.

Tujuan

Memungkinkan komunikasi antar-divisi secara terkontrol, tanpa menyatukan broadcast domain semua divisi.

Peran Router / L3 Switch

Menjadi default gateway tiap VLAN, memeriksa alamat tujuan, lalu meneruskan paket ke jaringan yang tepat.

VLAN ↔ Subnet

Praktik umum: 1 VLAN = 1 subnet IP. Contoh VLAN 10 → 192.168.10.0/24.

Switching vs Routing

AspekSwitching (Layer 2)Routing (Layer 3)
Dasar keputusanMAC Address tujuanIP Address tujuan
Satuan dataFramePaket (packet)
LingkupDalam satu VLAN / broadcast domainAntar jaringan / subnet berbeda
BroadcastDiteruskan dalam VLAN yang samaTidak diteruskan antar jaringan
Analogi: VLAN adalah kelompok ruangan yang dipisahkan. Router bertindak sebagai petugas penghubung yang memeriksa alamat tujuan dan menentukan jalur komunikasi antarkelompok. Analogi ini hanya membantu pemahaman; penjelasan teknisnya ada pada langkah-langkah di bawah.

05 · Alasan

Mengapa Inter-VLAN Routing Dibutuhkan?

VLAN sengaja dibuat terpisah, tetapi dalam kenyataannya divisi-divisi tetap perlu berbagi sumber daya tertentu seperti server, printer, atau aplikasi internal.

1. Switch Layer 2 tidak melakukan routing

Switch biasa hanya meneruskan frame di dalam satu VLAN. Frame dari VLAN 10 tidak akan dimasukkan ke VLAN 20.

2. Subnet berbeda

VLAN berbeda memakai subnet berbeda. Komunikasi antar-subnet memerlukan perangkat yang memahami alamat IP (Layer 3).

3. Broadcast tidak menyeberang

ARP broadcast hanya sampai ke anggota VLAN yang sama. PC tidak bisa mencari MAC tujuan di VLAN lain; ia harus menuju gateway.

4. Titik kontrol

Karena semua lalu lintas antar-VLAN melewati perangkat Layer 3, di situlah kebijakan (ACL/firewall) dapat diterapkan.

06 · Pengalamatan

Konsep Default Gateway

Default gateway adalah alamat IP perangkat Layer 3 (pada VLAN yang sama dengan PC) yang menjadi jalur keluar ketika tujuan berada di luar subnet lokal. Setiap subnet memerlukan gateway yang berada di subnet itu sendiri.

Hubungan IP, Mask, Gateway

IP + subnet mask menentukan network PC. Gateway harus berada di network yang sama agar PC bisa menjangkaunya langsung melalui ARP.

Jika gateway salah?

PC tetap bisa berkomunikasi di dalam VLAN-nya, tetapi gagal ke subnet lain karena paket dikirim ke alamat yang tidak ada atau tidak dapat dijangkau.

07 · Materi Utama

Router on a Stick

Router on a Stick adalah metode Inter-VLAN Routing yang menggunakan satu link fisik antara router dan managed switch. Link itu dikonfigurasi sebagai trunk di sisi switch dan dibagi menjadi beberapa subinterface logis di sisi router, satu untuk setiap VLAN.

Fungsi trunk

Membawa frame dari banyak VLAN melewati satu kabel dengan label (tag) IEEE 802.1Q.

Fungsi subinterface

Antarmuka logis pada satu antarmuka fisik router. Tiap subinterface dikaitkan dengan satu VLAN dan memiliki IP gateway VLAN tersebut.

Hubungan VLAN ID

VLAN ditentukan oleh perintah encapsulation dot1Q <VLAN-ID>, bukan oleh nama subinterface.

Jangan salah paham: nama subinterface seperti G0/0.10 tidak otomatis menentukan VLAN 10. Angka setelah titik hanyalah konvensi penamaan agar mudah dibaca. Hubungan VLAN ditentukan oleh enkapsulasi VLAN ID pada konfigurasi subinterface.

Kelebihan & Kekurangan

Kelebihan

  • Hemat: hanya satu port/kabel router
  • Cukup dengan router + managed switch Layer 2
  • Mudah dipraktikkan di Packet Tracer
  • Pas untuk jaringan kecil

Kekurangan

  • Semua trafik antar-VLAN berbagi kapasitas satu link
  • Router menjadi titik tunggal kegagalan dan potensi bottleneck
  • Kurang skalabel untuk VLAN dan trafik besar

Kapan sesuai digunakan? Pada sekolah, laboratorium, atau kantor kecil dengan beberapa VLAN dan trafik antar-VLAN yang tidak terlalu tinggi, terutama bila perangkat yang tersedia hanya router dan switch Layer 2.

Jika VLAN native (untagged) dipakai pada trunk router, subinterface-nya dapat diberi kata kunci native, misalnya encapsulation dot1Q 99 native. Pada praktik BAB ini kita tidak memakai VLAN native khusus.
09 · Alternatif

Layer 3 Switch

Layer 3 Switch adalah switch yang selain meneruskan frame (Layer 2) juga mampu melakukan routing antar-subnet (Layer 3). Routing dilakukan di dalam perangkat yang sama menggunakan Switch Virtual Interface (SVI).

AspekLayer 2 SwitchLayer 3 Switch
Keputusan penerusanMAC AddressMAC Address dan IP Address
Routing antar-VLANTidak bisaBisa (bila diaktifkan & didukung)
Gateway VLANHarus perangkat lainSVI pada switch itu sendiri

SVI

Interface virtual (interface vlan 10) yang menjadi gateway VLAN tersebut. SVI umumnya baru berstatus up bila VLAN ada dan minimal satu port aktif pada VLAN itu.

ip routing

Perintah global yang mengaktifkan fungsi routing pada switch Layer 3. Tanpa ini, SVI ada tetapi switch tidak merutekan antar-VLAN.

Penggunaan

Banyak dipakai pada jaringan perusahaan dan kampus dengan banyak VLAN dan trafik antar-VLAN yang besar.

Contoh konsep konfigurasi

vlan 10
vlan 20
vlan 30

interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown

interface vlan 30
 ip address 192.168.30.1 255.255.255.0
 no shutdown

ip routing
Perhatian: sintaks dan dukungan routing bergantung pada model switch dan sistem operasinya. Tidak semua managed switch mendukung Layer 3. Di Packet Tracer, misalnya, switch seri 3560 mendukung ip routing, sedangkan switch seri 2960 pada umumnya tidak. Selalu periksa spesifikasi perangkat.

Perbedaan konseptual kedua metode

Router on a Stick: routing menggunakan router dan subinterface; switch cukup Layer 2 dengan trunk ke router.
Layer 3 Switch: routing dilakukan oleh switch yang mendukung fungsi Layer 3, biasanya menggunakan SVI.

14 · Praktik Packet Tracer

Praktik 3 — Pengujian Komunikasi

Gunakan ping dari Command Prompt PC untuk membuktikan Inter-VLAN Routing berfungsi.

PC Admin>    ping 192.168.10.1     (gateway sendiri)
PC Admin>    ping 192.168.20.10    (PC Keuangan)
PC Keuangan> ping 192.168.30.10    (PC IT)
PC IT>       ping 192.168.10.10    (PC Admin)

Ujilah: (1) PC Admin ke gateway sendiri, (2) PC Admin ke PC Keuangan, (3) PC Keuangan ke PC IT, (4) PC IT ke PC Admin.

Keberhasilan ping dipengaruhi konfigurasi IP, gateway, VLAN, trunk, router, dan kondisi perangkat. Ping pertama dapat gagal (Request timed out) sesaat karena proses ARP atau kondisi awal simulasi. Ulangi ping sebelum menyimpulkan gagal.
