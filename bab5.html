4

Pengertian Routing

Routing adalah proses router memilih jalur untuk meneruskan paket IP menuju jaringan tujuan. Router seperti petunjuk arah yang menentukan jalur agar paket mencapai tujuan.

Fungsi routing
  • Menghubungkan jaringan berbeda subnet
  • Menentukan jalur terbaik/yang dikonfigurasi
  • Meneruskan paket berdasarkan IP tujuan
Switch vs Router
  • Switch: Layer 2, MAC address, dalam satu jaringan
  • Router: Layer 3, IP address, antarjaringan
Satu subnet vs beda subnet
  • Satu subnet: komunikasi langsung lewat switch
  • Beda subnet: wajib lewat router (gateway)
Hubungan dengan IP

Router mencocokkan network dari IP tujuan dengan entri Routing Table.

5

Routing Table

Routing Table adalah tabel di router berisi jaringan yang dikenal dan jalur menujunya. Router membaca tabel ini setiap kali menerima paket.

DestinationNext HopInterfaceJenis
192.168.10.0/24-G0/0Connected
10.0.0.0/30-G0/1Connected
192.168.20.0/2410.0.0.2G0/1Static
0.0.0.0/010.0.0.2G0/1Default
  • Destination Network + Prefix: jaringan tujuan
  • Next Hop: IP router berikutnya. Tanda - pada Connected Route = terhubung langsung, tidak butuh router lain
  • Outgoing Interface: interface untuk keluar
  • Metric: nilai biaya jalur (dipakai saat ada beberapa pilihan)
  • Sumber rute: Connected (otomatis), Static (manual), Default (0.0.0.0/0)
Longest prefix match: bila beberapa rute cocok, router memilih yang prefix-nya paling panjang (paling spesifik). Tujuan 192.168.20.10 cocok dengan /24 dan 0.0.0.0/0, maka dipilih /24.
6

Cara Membaca Routing Table

  1. Baca IP tujuan paket
  2. Cari network tujuan di Routing Table
  3. Tentukan Next Hop
  4. Tentukan interface keluar
  5. Teruskan paket

Coba Cari Jalur Paket

Coba: 192.168.20.10, 10.0.0.2, lalu 8.8.8.8 dengan dan tanpa Default Route.

7

Static Routing

Static Routing adalah rute yang dikonfigurasi manual oleh administrator: destination network, subnet mask, dan next hop (atau outgoing interface).

Kelebihan
  • Sederhana dan ringan
  • Tanpa trafik protokol routing
  • Mudah diprediksi
Kekurangan
  • Manual, rawan salah ketik
  • Tidak adaptif jika link putus
  • Sulit untuk jaringan besar
Kapan dipakai
  • Jaringan kecil (dua gedung)
  • Satu jalur keluar
  • Jalur yang ingin dikontrol penuh
Contoh: Gedung A 192.168.10.0/24 dan Gedung B 192.168.20.0/24 dihubungkan dua router. Setiap router harus tahu rute ke jaringan di belakang router lain.

R1: ip route 192.168.20.0 255.255.255.0 10.0.0.2
R2: ip route 192.168.10.0 255.255.255.0 10.0.0.1
8

Destination Network & Next Hop

Destination Network
Jaringan tujuan yang ingin dicapai (seperti "kota tujuan").
Next Hop
IP router berikutnya yang menerima paket (seperti "gerbang tol berikutnya").
KomponenContoh
Destination Network192.168.20.0/24
Next Hop10.0.0.2
Outgoing InterfaceG0/1

Hubungan: untuk mencapai Destination, kirim paket ke Next Hop lewat Interface. Next Hop harus berada di jaringan yang terhubung langsung dengan router.

Latihan

9

Default Route

Default Route (0.0.0.0/0) dipakai ketika tidak ada rute yang lebih spesifik. Biasanya mengarah ke router gateway/Internet.

ip route 0.0.0.0 0.0.0.0 10.0.0.2
! ip route = perintah rute statis
! 0.0.0.0 0.0.0.0 = semua jaringan (tujuan apa pun)
! 10.0.0.2 = next hop (router gateway)

Studi kasus: router kantor mengirim semua trafik yang tidak tercantum spesifik di Routing Table ke router gateway.

Simulasi pilihan rute

Jangan memasang Default Route sembarangan pada topologi dua gedung yang hanya butuh dua subnet. Next Hop harus benar-benar router berikutnya yang dapat dijangkau.

Studi Kasus

Kasus: tanpa rute
PC0 (192.168.10.10) ping PC2 (192.168.20.10). R1 hanya mengenal 192.168.10.0/24 dan 10.0.0.0/30, sehingga 192.168.20.0/24 tidak ditemukan dan paket dibuang. Solusi: Static Route di R1.
Kasus: balasan hilang
R1 sudah punya rute ke Gedung B, tetapi R2 belum punya rute ke 192.168.10.0/24. Paket sampai, balasan tidak kembali. Routing harus dua arah.

Praktik 1: Topologi Dua Router

Gunakan Cisco Packet Tracer. Perangkat: 2 Router, 2 Switch, 4 PC, kabel sesuai interface.

  • PC: perangkat pengguna
  • Switch: menghubungkan PC dalam satu LAN
  • Router: menghubungkan LAN dengan jaringan lain
KoneksiKabel yang umum dipakai
PC ke Switch; Switch ke RouterCopper Straight-Through
Router ke Router (Ethernet langsung)Copper Cross-Over (sesuai metode pembelajaran)
Kabel crossover pada koneksi router-router dipakai pada metode ini. Perangkat modern dengan auto-MDIX atau simulasi tertentu juga dapat bekerja dengan kabel jenis lain, jadi crossover tidak selalu wajib.

Praktik 3: Static Routing via CLI

Contoh Cisco IOS. Sesuaikan nama/nomor interface dengan model router.

Router 1
enable
configure terminal
interface gigabitEthernet0/0

interface gigabitEthernet0/1

ip route 192.168.20.0 255.255.255.0 10.0.0.2
end
show ip route
Router 2
enable
configure terminal
interface gigabitEthernet0/0
 ip address 192.168.20.1 255.255.255.0
 no shutdown
 exit
interface gigabitEthernet0/1
 ip address 10.0.0.2 255.255.255.252
 no shutdown
 exit
ip route 192.168.10.0 255.255.255.0 10.0.0.1
end
show ip route

Kedua router butuh Static Route masing-masing: paket harus bisa pergi dan balasannya bisa kembali.

Destination 192.168.20.0, mask 255.255.255.0, next hop 10.0.0.2 (Router 2).
Menampilkan Routing Table. Rute connected ditandai C, static ditandai S, default S*.

Praktik 4: Static Routing via GUI

Belajar Routing Statis Melalui GUI

Konfigurasi router tidak selalu lewat CLI. Pada perangkat simulasi yang mendukung, gunakan tab Config. Nama menu dapat berbeda menurut model router dan versi Packet Tracer; bila Static Routing tidak tersedia di GUI, gunakan CLI.

  1. Buka Cisco Packet Tracer
  2. Tambahkan dua router
  3. Tambahkan dua switch
  4. Tambahkan empat PC
  5. Hubungkan semua perangkat
  6. Pilih kabel yang sesuai
  7. Atur IP interface Router 1 (tab Config, pilih interface)
  8. Atur IP interface Router 2
  9. Aktifkan interface (centang On)
  10. Atur IP setiap PC
  11. Atur Default Gateway setiap PC
  12. Buka tab Config pada router
  13. Cari menu Routing / Static
  14. Isi Destination Network
  15. Isi Subnet Mask
  16. Isi Next Hop
  17. Tambah rute di Router 1
  18. Tambah rute di Router 2
  19. Periksa hasil konfigurasi
  20. Uji komunikasi dengan ping
